# Watch Party — Terms of Use

_Last updated: 2026-05-05_

By installing and using the Watch Party Chrome extension you agree to the following:

## 1. What this is

Watch Party is a Chrome extension that lets one user (the "host") curate a YouTube playlist as a synchronized "channel" and lets other users ("viewers") join via a short code to watch on the real youtube.com page while a chat overlay runs alongside.

The extension is a thin client. It does not host video. All video playback happens on YouTube; YouTube's own [Terms of Service](https://www.youtube.com/t/terms) and [Community Guidelines](https://www.youtube.com/howyoutubeworks/policies/community-guidelines/) apply to everything you watch through it.

- Reverse-engineer the extension or its backend with intent to disrupt service for others.

## 3. Anonymous vs signed-in use

Anonymous use is supported. You can host channels and chat without signing in. Choosing "Sign in with Google" upgrades your anonymous account so your display name reflects your Google profile name and your channels survive a sign-out.

If you abuse the chat or hosting features while anonymous, the host of a channel can delete the channel, which wipes the chat history for everyone in that channel.
